# LocalSpoiler

Плагин для Vencord, позволяющий скрывать чужие сообщения под локальный спойлер или удалять их только у себя (как в Telegram).

## Возможности
- **Скрыть у себя (под спойлер)** — оборачивает текст и вложения в спойлер на вашем клиенте Discord.
- **Удалить у себя (как в ТГ)** — локально удаляет сообщение из чата без отправки запроса на сервер.
- Сохранение скрытых сообщений между переключениями каналов.
